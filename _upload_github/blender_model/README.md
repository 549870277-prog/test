# 东湖听涛景区示意沙盘

这是根据需求文案生成的概念模型，不是实测地图或建筑复原模型。

- `tingtao.blend`：可编辑 Blender 工程；原默认场景保留，沙盘位于独立场景。
- `tingtao.glb`：网页模型，包含中文网格标牌与语义属性。
- `tingtao_preview.png`：渲染预览。
- `tingtao_network.json`：10 个节点、12 条道路的连接关系及用户提供的估算距离。
- `build_tingtao.py`：在 Blender 中运行以新建沙盘场景。
- `export_tingtao.py`：在沙盘场景激活时运行以保存和导出。
- `export_validation.json`：GLB 文件头、节点和道路属性检查结果。

## 比例与坐标

范围采用用户提供的 WGS84 矩形：经度 114.3605–114.3695，纬度 30.5640–30.5715。
局部等距近似尺寸约 862.64 × 834.90 米，总矩形面积约 0.72 平方公里（包含模型湖面），与文案所述陆地面积 1.2–1.5 平方公里存在冲突。
比例 1:500，范围在模型中约 1.725 × 1.670 米；底座与标题条位于范围以外。
Blender 原点为矩形中心，X 向东、Y 向北、Z 向上。GLB 默认转换为 X 向东、Y 向上、Z 向南。
JSON 的 `model_position` 是 Blender 坐标；转换到 Three.js 为 `[x, z, -y]`。

## 前端接入

GLB 可由 Three.js GLTFLoader 加载，需要在前端设置光照。
标记名为 `marker_entry`、`marker_exit`、`marker_p1` 至 `marker_p5`、`marker_A` 至 `marker_C`。
glTF `extras` 对应 Three.js `object.userData`，其中 `node_id` 可用于点击识别。
道路对象名以 `road_` 开头，含 `from`、`to`、`estimated_length_m` 和 `surveyed=false`。
所有网格顶点使用统一的局部地图坐标，部分对象原点为地图原点；取景点定位请使用 JSON 节点位置。

## 已知边界

仅四角坐标由用户提供。内部景点位置、湖岸形态、地形、建筑与道路折线均为示意设计，未参考测绘或实景影像；不能用于实地导航。
道路保留需求中的估算距离属性，几何折线长度不等同于该距离。主步道宽 3 米、支路宽 2 米；建筑和标牌适度夸大以便浏览。
图中没有额外推断的可通行连接。交叉线的视觉相交不构成新增路口；导航连通性以 JSON edges 为准。
入口相对矩形角点向内留出标牌边距，不是入口的 GPS 坐标。
景点开放时间、票价、建筑细节等未进行事实核查，未写入可用于发布的介绍数据。
上线前应替换为已核实的岸线、景点坐标、道路中心线和通行属性。
